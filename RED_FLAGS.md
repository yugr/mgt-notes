Some phrases may be perceived by managers as potential "red flags", particularly when they indicate a lack of ownership, initiative or motivation.

Pay attention to "I did not complete X because of Y" where Y could reasonably be addressed, escalated or communicated about by the employee. The issue is usually not the blocker itself, but failing to take reasonable steps to resolve it or communicate about it.

Examples:
  - I did not complete my task because someone did not answer me
  - I did not complete my task because there was no info in docs (variant: because docs were unclear or docs were stale)
  - I did not complete my task because there was an error in CI (variant: because some command failed)
  - I did not complete my task because I did not know how to run tests
  - I did not complete my task because I was waiting for instructions
  - I did not complete my task because I did not understand it (variant: because requirements were unclear or it's not my job to improve requirements)
  - I did not complete my task because I did not have access to server (and I did not tell anyone about it until the deadline)
  - I did not complete my task because this was not my responsibility
  - I did not complete my task because I did not consider it important
  - I did not complete my task because X should do it (variant: because that's not my job)

Reporting problems without proposing next steps is somewhat similar:
  - X is broken
  - The documentation is wrong
  - The requirements are unclear

Another potentially concerning pattern is repeatedly saying "I am studying/analyzing/researching/looking into X" in daily meetings without being able to describe concrete progress, findings, next steps, or obstacles.
